# Analog Groups (Группы аналогов)

## Описание

Функциональность групп аналогов позволяет группировать взаимозаменяемые курсы (например, три версии математического анализа: синий, красный, черный), чтобы алгоритм рекомендаций автоматически предлагал только один курс из группы.

## Как это работает

### В базе данных

Курсы имеют поле `AnalogGroup` (строка), которое указывает к какой группе аналогов они относятся:

```go
type Course struct {
    // ... другие поля
    AnalogGroup string `gorm:"type:varchar(255);default:''"`
}
```

Например:
- Синий матан: `AnalogGroup = "Матан1"`
- Красный матан: `AnalogGroup = "Матан1"`
- Черный матан: `AnalogGroup = "Матан1"`

### В Google Sheets

При синхронизации из Google Sheets, значение группы берется из колонки:
- `Группа аналогов(алгоритм не берет больше 1 курса из группы)` или
- `Группа аналогов`

### Логика алгоритма

При построении roadmap алгоритм:

1. **Проверяет пройденные и запланированные курсы**: собирает все группы аналогов, которые уже выполнены студентом (курсы в `passedCourses` или `plannedSemesters`)

2. **Отмечает первый курс из группы**: при обходе требований специальности (major requirements), первый встретившийся курс из незаполненной группы аналогов помечается как "основной" для этой группы

3. **Виртуально отмечает остальные как пройденные**: все остальные курсы из уже заполненной группы помечаются как "виртуально пройденные" и:
   - Не добавляются в список обязательных курсов (`coreCourseIDs`)
   - Не планируются алгоритмом
   - Не вызывают ошибку "не удалось запланировать обязательный курс"

4. **Уважает выбор студента**: если студент уже взял или запланировал конкретный курс из группы, алгоритм не будет предлагать другие курсы из этой группы

## Примеры

### Пример 1: Новый студент (нет пройденных курсов)

Специальность требует: Синий матан, Красный матан, Черный матан (все в группе "Матан1")

**Результат**: алгоритм предложит только один курс (например, первый в списке - Синий матан)

### Пример 2: Студент прошел Синий матан

**Результат**: алгоритм НЕ будет предлагать Красный и Черный матан в будущих семестрах

### Пример 3: Студент запланировал Красный матан на следующий семестр

**Результат**: алгоритм НЕ будет предлагать Синий и Черный матан

## Важные замечания

- Студентам **не запрещено** брать несколько курсов из одной группы вручную
- Алгоритм просто **не будет автоматически предлагать** больше одного курса из группы
- Пустая строка в `AnalogGroup` означает что курс не принадлежит ни одной группе аналогов
- Группы аналогов работают независимо друг от друга (можно иметь "Матан1", "Физика1" и т.д.)
