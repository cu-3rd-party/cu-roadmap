# Инструкция по настройке групп аналогов

## Проблема
Алгоритм рекомендует несколько курсов из одной группы (например, два матана), хотя должен рекомендовать только один.

## Причина
В Google Sheets не заполнена колонка "Группа аналогов".

## Решение

### Шаг 1: Добавить колонку в Google Sheets
В каждом листе (Fundamentals, STEM, Бизнес и аналитика и т.д.) нужна колонка с названием:
- `Группа аналогов` или
- `Группа аналогов(алгоритм не берет больше 1 курса из группы)`

### Шаг 2: Заполнить группы для курсов

Для курсов, которые являются взаимозаменяемыми, указать **одно и то же** название группы.

#### Примеры групп:

**Математический анализ 1:**
- 🔴 Математический анализ. Основной уровень → `Матан1`
- ⚫️ Математический анализ. Пилотный поток → `Матан1`
- Любые другие варианты первого матана → `Матан1`

**Математический анализ 2:**
- 🔴 Математический анализ 2. Основной уровень → `Матан2`
- Основы математического анализа и линейной алгебры 2 → `Матан2`
- ⚫️ Математический анализ 2. Пилотный поток → `Матан2`
- Любые другие варианты второго матана → `Матан2`

**Линейная алгебра:**
- 🔴 Линейная алгебра и геометрия → `ЛинАлг1`
- ⚫️ Линейная алгебра. Продвинутый → `ЛинАлг1`

### Шаг 3: Перезапустить синхронизацию

После заполнения колонки в Google Sheets:

1. Войти как админ (пароль: `admin`)
2. Вызвать API для ресинхронизации:
```bash
POST http://127.0.0.1:8080/api/v1/courses/restore
```

Или перезапустить бекенд - синхронизация произойдет автоматически при старте.

### Шаг 4: Проверить

Проверить что поле заполнилось:
```bash
GET http://127.0.0.1:8080/api/v1/courses/?title=Математический
```

В ответе должно быть `"analog_group": "Матан1"` (или другое значение группы).

## Как это работает

После того как поле `analog_group` заполнено:
1. Алгоритм при построении roadmap смотрит какие группы аналогов уже выполнены (студент прошел или запланировал курс из этой группы)
2. Для выполненных групп алгоритм помечает остальные курсы из группы как "виртуально пройденные"
3. Эти курсы не добавляются в рекомендации

## Важно
- Студентам **НЕ запрещено** брать несколько курсов из одной группы вручную
- Алгоритм просто **не будет автоматически рекомендовать** больше одного курса из группы
- Пустое значение `analog_group` означает что курс не принадлежит ни к какой группе
