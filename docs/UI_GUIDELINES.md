# CU Roadmap UI Guidelines

These guidelines are based on the Central University Brandbook and internal design feedback.

## Design Tokens

### Colors
- **Primary Dark**: `#141414` (Main background, primary text)
- **Primary Light**: `#E6E6E6` (Surface areas, text on dark)
- **Accent Yellow**: `#FFDD2D` (Primary actions, key highlights)
- **Accent Blue**: `#3044FF` (Interactive elements, links)
- **Accent Green**: `#009B40` (Success states)
- **Accent Red**: `#E63F07` (Errors, critical warnings)
- **Accent Fuchsia**: `#DB44E8` (Secondary highlights)

### Typography
- **Font Family**: `Graphik`, sans-serif (Inter as fallback)
- **Headers**: `Graphik Semibold`
- **Subheaders**: `Graphik Medium`, Uppercase, Letter-spacing: 4%
- **Body Text**: `Graphik Regular`

### UI Patterns
- **Cards**: Unified height across grids to prevent layout "jumping".
- **Selection States**: High contrast. Use standard checkboxes for course selection.
- **Navigation**: Top-line sticky menu with anchors for quick section jumping.
